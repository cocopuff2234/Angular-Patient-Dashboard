# Angular Patient Search Dashboard

A responsive Angular application that recreates a healthcare patient search interface from a provided design mock.

## Features

- Basic and advanced patient search
- Dynamic filtering of patient data
- Tab navigation (Today's Patients / Search Results)
- Responsive layout for desktop and mobile
- Component-based Angular architecture

## Running the App

```bash
git clone https://github.com/cocopuff2234/Angular-Technical-Interview.git
cd Angular-Technical-Interview
npm install
ng serve

```
